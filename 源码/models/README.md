# 模型与训练文件说明

本目录包含 YOLO 训练脚本、数据拆分脚本、配置文件及命令行检测默认权重。

当前保存的训练记录、模型权重和数据划分尚未组成可从头复现并独立核验的完整评测链。因此本说明不把旧版结果文件中的指标作为已确认性能。若要复现实验，请固定数据清单、权重文件、训练参数和评测命令，并记录实际结果。

- n1_train.py：YOLO 训练入口。
- reshuffle.py：数据文件重新划分脚本；运行前先备份数据并检查脚本中的目标路径和划分逻辑。
- args.yaml：已有训练参数记录，含原环境路径，需按本机环境调整。
- best.pt：命令行端默认候选权重之一。

完整技术路线和结果说明见项目根目录的[项目介绍](../../项目介绍.md)与[使用说明](../../使用说明.md)。
